# SN95 Dyno Shop

Data-driven interactive chassis-dyno configurator for the 1996–1998 Non-PI 4.6 2V Mustang GT.

## Live Site
Once GitHub Pages is enabled (Settings → Pages), the site will be available at:
https://chexwave.github.io/sn95-dyno-shop/

## Structure
- `index.html` — Command center interface with digital boards and live curves
- `data/sn95_parts_database.json` — Parts matrix with real chassis-dyno ranges and notes

## Notes
Gains are approximate real-world chassis dyno averages from SN95 Non-PI 4.6 2V results. This is a reference / diagnostic tool, not a guarantee of results on any specific car.
